# SFMC Inventory Scripts

SSJS scripts for Salesforce Marketing Cloud inventory extraction.

## Scripts

### journey-inventory/journey_inventory.ssjs
Extracts Journey Builder data across all Business Units into a shared DE.

### cloudpage-inventory/cloudpage_inventory.ssjs
Extracts Cloud Page details across all Business Units into a shared DE.

## Setup
1. Replace YOUR_CLIENT_ID, YOUR_CLIENT_SECRET, AUTH_BASE_URI with real values
2. Update SOURCE_DE and TARGET_DE names to match your environment
3. Deploy as a Cloud Page in SFMC
